# Draftwise

Static Draftwise landing page prepared for Cloudflare Pages.

Live site: https://draftwise.pages.dev

## Files

- `index.html` — the complete site
- `assets/` — local fonts and hero background image
- `wrangler.jsonc` — Cloudflare Pages configuration

## Preview locally

```powershell
npx wrangler pages dev .
```

## Deploy

```powershell
npx wrangler pages deploy . --project-name draftwise
```
